Privacy Policy

The Auto Edits publishing tool · Last updated 30 October 2026

What this tool is

The Auto Edits publishing tool is a private application used only by the owner of the YouTube channel @TheAutoEdits. It is not offered to the public, and no one else signs in to it.

What it accesses, and why

When the channel owner signs in with Google, the tool asks for these permissions:

  • Upload YouTube videos (youtube.upload): to publish the channel's own Shorts.
  • View your YouTube account (youtube.readonly): to read view, like and comment counts for the channel's own videos.
  • View YouTube Analytics reports (yt-analytics.readonly): to read watch time and traffic sources for the channel's own videos.

It uses these only for the channel owner's own account. It does not access any other person's data.

Where data is kept

The sign-in token and the statistics the tool reads are stored only on the channel owner's own computer. They are not sold, shared or sent to anyone else, and they are not used for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

This tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time from your Google Account's third-party access settings. Deleting the token file on the owner's computer also removes it.
