Auto Edits Runbook

Every command, what it's for, and what it costs you if you skip it.

Every command on this page assumes the virtualenv is active. Running without it is what produced streamlit: command not found and ModuleNotFoundError: googleapiclient. Start every session with: 
cd ~/autoedits && source .venv/bin/activate
python -m autoedits.doctor will tell you if you forgot.

When you sit down

python -m autoedits.doctor

Pre-flight. Checks Python, Ollama, the voice engine, the YouTube token and the source audit. Run it first and nothing else surprises you.

streamlit run review_app.py

The review app — Drafts, Approved, Performance. Nothing publishes without you ticking it here.

The two lanes

The automation is two separate things that share a renderer, a review queue and an upload path. They have never been the same program.

LaneWhat starts itWhat it makes
Regular
pipeline.py		 The nightly cron, on its own Data shorts from curated UAE rules and prices. Runs whether you are there or not.
Events
photo_short.py		 You, after a meet or a show Shorts from your own photographs. Nothing in them can be claimed by Content ID, because you shot all of it.

Keep them separate deliberately. The regular lane is allowed to run unattended because every figure in it is gated against an official source. The event lane can never run unattended, because naming a car is a judgement and a wrong model costs more than a silent frame.

Making a video

Three routes. They differ by who writes the script.

1. The nightly queue the model writes it

python -m autoedits.pipeline

Takes topics off the queue, writes scripts with the local model, renders drafts. Right for volume. Wrong when the angle is the whole point — asked about a fines table, a 7B model writes "here are the fines".

2. A script you wrote you write it

mkdir -p work/my-slug
$EDITOR work/my-slug/spec.json
python -m autoedits.pipeline --from-spec my-slug

Skips the model, keeps everything after it: voice, render, sourcing gate, draft in the queue. Use it when the hook matters more than the throughput. The sourcing gate still applies — writing it yourself is not evidence.

3. Your own photographs no script at all

After an event, scaffold the day. An event is a date, and your camera already puts the date in the filename:

python -m autoedits.photo_short --scaffold 20260117

Finds everything shot that day, orders it the way you walked round, and writes a manifest into data/meets/. Anything too small to fill a vertical frame or too soft to survive full size is held back as a commented line with the reason — uncomment it if you disagree.

Captions come out blank on purpose. That is the one part no tool should guess: a VENOM-badged 991 went out of here labelled as a RUF. Fill in the title, the captions you are sure of, then build:

python -m autoedits.photo_short data/meets/20260117.txt --draft
python -m autoedits.photo_short --all --draft
Re-render without redoing the voice. Voice takes about fifteen minutes on this box. If a render fails after it: 
python -m autoedits.pipeline --rebuild my-slug

Publishing

python -m autoedits.publish

Uploads everything you approved in the review app. Nothing else.

Checking the numbers

CommandWhat it answers
python -m autoedits.analytics 90 Retention, traffic sources, and subscribers per 1,000 views per video. Loops under about 0.30 means the format failed, not the topic.
python -m autoedits.audit --likes Likes and like-rate for every Short on the channel. A healthy Short is 2–5%. Add --all for long-form too.
python -m autoedits.audit The whole back catalogue into data/channel_audit.csv — the view before any decision about the 479 videos.
python -m autoedits.reconcile Why the review app and YouTube Studio disagree about views. They use different counters; this shows all of them side by side.
python -m autoedits.publish --metrics Pulls views/likes/comments into the local database for the Performance tab.

Checking the facts

python -m autoedits.sources
python -m autoedits.sources --list

Audits every legal claim against the source registry. A claim about what the law requires must come from a primary or official source — uaelegislation.gov.ae, u.ae, RTA, MoI, the Central Bank rulebook. Press is fine for that a rule changed, never for what it says. Rows that fail are withheld from retrieval, so they cannot become videos.

python -m autoedits.topics --evergreen
python -m autoedits.topics --probe "car insurance uae"

Refill the topic queue. Evergreen questions load at the top, because their answers don't expire.

Already automatic

The nightly cron runs the pipeline and leaves drafts. It never publishes. You don't need to run anything to make that happen — only to review it.

The seven-day trap

While the Google Cloud consent screen sits in Testing, Google kills your refresh token after seven days. Uploads stop. Drafts pile up looking fine. Nothing tells you.

python -m autoedits.publish --check    # weekly. is the connection alive?
python -m autoedits.publish --auth     # re-authorise when it isn't

The permanent fix: Google Cloud Console → APIs & Services → OAuth consent screen → Publishing status → Publish app. Tokens then last until you revoke them. You'll see an "unverified app" warning at sign-in — Advanced → Go to The Auto Edits. It's your own app and you're the only user.

When something breaks

SymptomCause
command not found The venv isn't active. source .venv/bin/activate.
ModuleNotFoundError Same. You're on system Python.
invalid_grant Token expired or the OAuth client changed. publish --auth. Replacing client_secret.json does not fix this — token.json is the dead file.
Views don't match Studio Expected. Different counters. reconcile.
A draft was skipped A number in it had no traceable source. That gate is deliberate.
Photos render sideways Fixed — ImageOps.exif_transpose in render.py. If it returns, that import went missing.
